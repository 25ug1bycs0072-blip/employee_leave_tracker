# Orbit People — Leave Tracker

Open `index.html` in a modern browser to use the demo. No build step or dependencies are required.

The demo includes employee management, leave requests and approvals, balance checks, a leave calendar, audit history, and CSV/print exports. Data is saved in browser local storage; use **Settings → Reset demo data** to restore the sample workspace.

This is a front-end prototype, not a production HR system. It does not provide server-side accounts or role enforcement, a shared database, real notifications, or secure document storage. The supporting-document control records a filename only. Do not enter real employee or confidential data.
